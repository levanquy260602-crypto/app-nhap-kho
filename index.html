☁️ Kết Nối Cơ Sở Dữ Liệu Đám Mây (Supabase Cloud Sync)

Chế độ Cục bộ (Offline)

Khi kết nối Đám mây Supabase (miễn phí), mọi thao tác lập phiếu, nhập/xuất kho từ máy tính cơ quan, máy ở nhà hoặc điện thoại sẽ được tự động đồng bộ tức thì theo thời gian thực mà không cần copy file thủ công.

📖 Hướng dẫn 3 bước tạo Database Supabase miễn phí (chỉ mất 2 phút)

Bước 1: Truy cập supabase.com ➡️ Đăng nhập bằng Google hoặc GitHub ➡️ Bấm "New project" (Đặt tên ví dụ: kho-phap-y).

Bước 2: Vào mục SQL Editor ở menu bên trái của Supabase, dán đoạn mã sau vào rồi nhấn nút Run:

-- Tạo bảng lưu trữ cơ sở dữ liệu kho Pháp Y
CREATE TABLE IF NOT EXISTS public.forensic_inventory (
  id TEXT PRIMARY KEY,
  data JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Cho phép ứng dụng đọc/ghi dữ liệu
ALTER TABLE public.forensic_inventory ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public read/write" ON public.forensic_inventory
  FOR ALL USING (true) WITH CHECK (true);

Bước 3: Vào mục Project Settings ➡️ API ➡️ Sao chép Project URL và anon / public key dán vào 2 ô ở trên, bấm "Lưu & Bật Đám Mây" là xong!
