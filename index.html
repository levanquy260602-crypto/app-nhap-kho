☁️ Kết Nối Cơ Sở Dữ Liệu Đám Mây (Supabase Cloud Sync)

Chế độ Cục bộ (Offline)

Kết nối Đám Mây được cấu hình cố định trong file js/config.js. Mọi máy (máy cơ quan, điện thoại) chỉ cần mở địa chỉ trang web và đăng nhập tài khoản Thủ kho là đồng bộ. Khoa / Phòng gửi phiếu đề xuất không cần đăng nhập và không xem được dữ liệu kho.
Tài khoản đang đăng nhập: ---

📖 Hướng dẫn 3 bước tạo Database Supabase miễn phí (chỉ mất 2 phút)

Bước 1: Tạo project trên supabase.com (nếu chưa có).

Bước 2: Vào SQL Editor, dán toàn bộ nội dung file supabase/security_upgrade.sql (có trong mã nguồn) rồi bấm Run. File này khóa dữ liệu kho, chỉ cho tài khoản Thủ kho đọc / ghi, tạo hộp thư phiếu đề xuất và nhật ký thay đổi.

Bước 3: Vào Authentication → Sign In / Providers, tắt Allow new users to sign up. Sau đó vào Authentication → Users → Add user tạo tài khoản Thủ kho (tích Auto Confirm User), rồi chạy đoạn SQL cấp quyền ở mục 7 cuối file.

Bước 4: Mở file js/config.js, điền Project URL và khóa anon / public (tuyệt đối không dùng khóa service_role), đẩy lên GitHub để Vercel cập nhật.

Lưu ý: Link đồng bộ kiểu cũ ?cloud=... gửi qua Zalo trước đây không còn tác dụng. Nên xóa các tin nhắn chứa link đó.
